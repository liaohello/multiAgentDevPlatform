## 技术验证不等同于偏好确认

DeepSeek Responses 连接、Thread 续接、推理强度切换、Skill 发现隔离、Token 归属、WSL 取消和崩溃恢复应通过小实验解决，不要求用户猜测 API 行为。结果失败时先给出证据与最小替代方案，再讨论是否改变已有设计。
